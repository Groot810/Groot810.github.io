# Infinite Canvas

一个基于 Vue 3 和 TypeScript 的无限画布 AI 工作流工具。文本、图片、视频和音频节点通过有向连线传递上下文，每类节点可以独立配置 OpenAI 兼容模型服务。

## 本地运行

环境要求：Node.js `^22.18.0` 或 `>=24.12.0`。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

构建结果位于 `dist/`。Vite `base` 已设置为 `./`，可用于静态部署和桌面网页封装。

## 快速使用

1. 从左侧新建文本、图片、视频或音频节点，也可以点击“添加”上传本地文件。
2. 从上游节点右侧端口连接到下游节点；箭头方向就是数据流方向。
3. 在目标节点中填写提示词、选择模型和角色。
4. 点击“生成”。系统只读取指向当前节点且已启用的直接上游输入。
5. 首次调用前，在右上角“配置”中填写对应类型的 Base URL、API Key 和模型名称。

## 画布操作

- 在空白区域拖动可平移无限画布，节点四角可调整大小。
- 右上角可以切换“鼠标模式”和“触控板模式”，选择会保存在浏览器中。
  - 鼠标模式：滚轮围绕光标缩放。
  - 触控板模式：双指滑动平移，捏合缩放。
- 右下角提供缩放、复位、小地图和清空画布操作。
- 点击画布名称可以重命名、新建、切换、删除、导入或导出画布。
- 画布会自动保存在当前浏览器；API Key 只保存在当前会话。

## 节点与连线

连线表示真实的数据依赖。`A → B` 表示执行 B 时读取 A，B 不会反向影响 A。

- 支持一个节点连接多个下游，也支持一个节点接收多个上游。
- 禁止自连接、重复连接和循环依赖。
- 连线可以调整输入顺序、停用、启用或删除。
- 删除或停用连线后，该上游立即停止参与下游生成。
- 上游内容变化后，下游显示黄色状态点，但不会自动重新生成。
- 当前只读取一层直接上游，不递归展开整条链路。

## 文本节点

- 输入区支持提示词、草稿和任务说明；占位文字不会作为内容发送。
- 输入 `@` 可以引用已连接的文本、图片、视频或音频资源，图片以真实缩略图显示。
- 点击“生成”调用文本模型，结果显示在节点下半部分。
- 双击 AI 结果可编辑；输入区与结果区之间的分割线可以上下拖动。
- 点击“生图”会在右侧创建并连接图片节点，但不会自动开始生成。
- “保存提示词”可选择保存生成前输入或生成后结果。

## 图片节点

- 支持上传、替换、放大、下载和反推提示词。
- 设置面板支持自动、1:1、3:2、2:3、16:9、9:16 或自定义宽高。
- 每次可生成 1–8 张图片；第一张写回当前节点，其余结果排列在右侧。
- 当前节点已有图片时，会把原图作为参考图生成新批次。
- 单击 AI 生成图片可打开修改面板；修改结果创建为新节点，不覆盖原图。
- 图片下载文件名使用日期和时间。

## 视频节点

- 支持上传本地视频和真实视频生成。
- 设置面板支持自动或自定义画面比例、1–15 秒时长、720p 或 480p 分辨率。
- 生成使用 OpenAI 风格异步 Videos API：创建任务、轮询状态并下载最终视频。
- 具体可用比例、时长和分辨率取决于所选服务与模型。

## 音频节点

- 支持上传本地音频和通过 `/audio/speech` 生成音频。
- 节点内提供播放、暂停、进度拖动、音量和静音控制。
- 右上角菜单提供播放速度、从头播放和下载。
- 当前默认使用 `alloy` 声音和 MP3 格式，朗读内容最多 4096 字。

## 媒体生成输入

单击图片、视频或音频节点，会在节点下方展开生成输入区。

- 输入文字只作为当前生成提示词，生成后不会被覆盖。
- “添加”可以上传任意支持的文本、图片、视频或音频，并自动创建上游节点和连线。
- “选择角色”把角色系统提示词加入当前节点请求。
- 模型下拉框只显示与当前媒体类型匹配的渠道。
- 输入区为空时，“保存当前提示词”不可用。

## 我的提示词

- 可以保存文本、图片、视频和音频提示词，最多 100 条。
- 保存时会检查正文；内容完全相同的提示词不会重复保存。
- “我的提示词”支持直接新增、修改、删除和类型标签调整。
- 点击提示词卡片会关闭管理界面，并把内容写入当前节点。
- 点击“提示词库”可浏览 6 个公开提示词来源；支持按来源、标签分类和关键词筛选。
- 标签默认只显示一行，点击右侧箭头可以展开全部标签或重新收起。
- 公开提示词卡片显示标题、正文摘要、类型、标签、作者和来源；点击后会写入当前节点。
- 提示词库按需从公开 JSON 加载，只缓存在当前页面内，不占用画布的本地存储空间。

### 统一 JSON 数据

本项目不在浏览器中直接解析上述 6 个仓库的不同原始格式，而是读取 [yukkcat/image-prompts 的 `dist/sources`](https://github.com/yukkcat/image-prompts/tree/main/dist/sources) 发布的统一格式静态 JSON。

`image-prompts` 负责集中抓取、解析、字段标准化和数据校验，并按来源生成 JSON；本项目通过 `fetch()` 按需读取这些结果，用于搜索、来源筛选、标签筛选、详情预览和写入节点。当前使用的文件包括：

- `banana-prompt-quicker.json`
- `davidwu-gpt-image2-prompts.json`
- `awesome-gpt-image.json`
- `awesome-gpt4o-image-prompts.json`
- `youmind-gpt-image-2.json`
- `youmind-nano-banana-pro.json`

统一 JSON 只是数据分发和格式适配层，不是提示词或参考图片的重新授权方。同步程序使用 MIT License；各提示词、示例图片、作者署名和其他内容的权利与许可仍以对应上游项目为准。本项目保留数据中的来源名称、作者和原始链接，使用或再分发前请同时检查对应上游仓库的许可证与署名要求。

## 角色管理

- 每个节点可以选择独立角色。
- 角色包含名称和系统提示词，最多创建 30 个。
- 角色只影响选择它的节点，不会修改全局系统提示词。
- 支持更换、清除和删除角色。

## 模板与文件

- “我的模板”和“模板库”都分为“画布模板 / 提示词模板”。
- 我的画布模板保存节点类型、尺寸、位置和连线，不保存用户文件、提示词或生成结果；最多 10 个。
- “我的模板 → 提示词模板”直接读取“我的提示词”的保存记录，两处内容、类型、修改和删除状态完全同步，最多 100 条。
- 可以从提示词模板列表使用或删除记录，也可以把当前选中节点的内容保存到“我的提示词”。
- 使用提示词模板时优先写入类型匹配的当前节点；没有匹配节点时自动创建文本、图片、视频或音频节点。
- “模板库”包含随项目发布的公共画布模板和公共提示词模板，均可直接使用。
- 左侧“添加”可以识别支持的文本、图片、视频和音频格式，并创建对应节点。
- 文本文件会读取实际文字；格式不支持、编码无法读取或文件损坏时会显示错误。

## 模型配置

文本、图片、视频和音频服务相互独立，每类最多配置 5 个渠道。每个渠道包含：

- 渠道名称
- 服务名称
- API Base URL
- API Key
- 模型名称
- 温度
- 最大输出长度

默认配置：

| 类型 | Base URL | 模型 |
|---|---|---|
| 文本 | `https://api.openai.com/v1` | `gpt-5.5` |
| 图片 | `https://api.openai.com/v1` | `gpt-image-2` |
| 视频 | `https://api.openai.com/v1` | `sora-2` |
| 音频 | `https://api.openai.com/v1` | `gpt-4o-mini-tts` |

Base URL 会直接使用，不会自动补 `/v1`。“测试模型”请求 `GET <Base URL>/models`；不提供该端点的兼容服务需要手动确认模型名称。

## 保存与导出

- 节点、连线、视口、模板、角色和提示词库保存在浏览器本地。
- 画布导出为 ZIP：根目录包含 `canvas.json`，`file/` 保存仍被节点引用的媒体文件。
- “导入画布”只接受本项目导出的 ZIP，并校验画布结构和文件。
- 远程资源受跨域和链接有效期影响，无法读取时会保留原 URL 并记录跳过原因。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` | 重做 |
| `Ctrl/Cmd + S` | 保存画布 |
| `Delete` / `Backspace` | 删除选中的节点或连线 |
| `Esc` | 取消连接 |
| `Ctrl/Cmd + Enter` | 完成 AI 结果编辑 |

输入框、文本编辑区和媒体提示词区域获得焦点时，删除快捷键不会删除节点。

## 注意事项

- 网页直接请求模型服务，服务端需要允许当前网页来源的跨域请求。
- 第三方“OpenAI 兼容”服务是否接受图片、视频或音频格式，以服务方协议为准。
- 图片批量生成按张请求，数量越多，耗时和费用越高。
- “吸附到网格”等少数偏好仍只保存设置，尚未完整接入交互逻辑。
